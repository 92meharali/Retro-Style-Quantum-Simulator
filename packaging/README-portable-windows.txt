Quantum Circuit Lab — Portable (Windows x64)
=============================================

Interactive state-vector quantum circuit simulator (2–12 qubits).

Quick start
-----------
  Double-click run.bat
  — or —
  Double-click quantum-lab.exe

Requirements
------------
  • Windows 10 or 11 (64-bit)
  • OpenGL 3.3+ (included with standard GPU drivers)

Contents
--------
  quantum-lab.exe   Application
  presets\          Built-in circuit library
  run.bat           Launcher
  README.txt        This file

User data (created on first run)
--------------------------------
  %APPDATA%\quantum-lab\   Settings and user presets

Tips
----
  • File menu: import/export JSON, OpenQASM, PNG
  • Pick a gate, click a circuit cell
  • CNOT/CZ: click control wire, then target wire

If Windows SmartScreen warns about an unknown publisher, click
"More info" → "Run anyway" (this is an unsigned educational build).
